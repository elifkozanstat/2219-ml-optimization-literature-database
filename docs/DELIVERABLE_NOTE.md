# D1.2 Deliverable Note

An open and structured literature database was developed to document the optimization and learning methods reviewed during Work Package 1. The database contains 57 records and covers gradient-based optimization, robust and adaptive loss design, heuristic/metaheuristic optimization, classical shortest-path methods, learned road-network distance indexes, and distance/travel-time estimation approaches. Each record includes bibliographic information together with method, objective/loss, adaptivity, robustness focus, evaluation setting, source-verification status, and relevance to the research. The database was designed as an auditable research artifact and served as the evidence base for the completed ranking (D1.3) and deficiency analysis (D1.4). Preprints are explicitly distinguished from peer-reviewed publications, and the level of source review is recorded to avoid overstating the evidence checked.
